## Taiwan Talka - 台灣在地化語音辨識系統
**獨立開發者** | 2025年5月 – 2025年7月

打造針對台灣在地口音優化的 macOS 語音辨識應用，支援台語、國台語混合、中英文晶體 (code-switching) 的高準確度辨識，並針對 Apple Silicon 進行深度效能優化。

* 設計 CoreML Encoder (Apple Neural Engine 加速) + GGML Decoder (Metal GPU 加速) 的異構運算架構，在 M2 Air 16GB 上達成 >30% 推理速度提升
* 透過混合精度量化策略 (FP16/Q5K) 與硬體加速器充分利用，將記憶體佔用控制在 < 2GB，避免 swap 影響使用體驗
* 基於開源微調語音模型進行本地化部署，實現隱私保護與低延遲推理
* 針對台語、國台語夾雜、中英文晶體等台灣特有語境進行辨識準確度優化
* 解決 Encoder-Decoder 跨框架權重一致性驗證問題與模型適配挑戰

**技術棧:** Python, CoreML, GGML, Metal GPU, Apple Neural Engine, Whisper Architecture

## LUMACOOL DELIVERY APP
**產品負責人 / 全端開發** | 2024年10月 – 2025年4月

為解決主流外送平台的高抽成問題，獨立完成「Lumacool Delivery」從零到一的後端系統架構設計與開發。專案不僅實現了複雜的商業邏輯，更在架構選型、設計模式應用、安全性與自動化維運上，進行了全面的工程實踐。

* 採用 Python FastAPI 框架，並基於 asyncio 實現了全非同步處理，高效應對來自顧客、商家與外送員的多方高併發請求，最大化系統吞吐量
* 系統嚴格遵循三層式架構：API 層 (Routers) 處理 HTTP 請求、業務邏輯層 (Services) 封裝核心商業規則、資料存取層 (Repositories) 負責與資料庫互動，實現業務邏輯與資料存取的徹底解耦
* 利用 Pydantic 進行嚴格的數據模型定義與驗證，確保 API 的穩定性與數據一致性
* 設計並實現了基於 JWT (JSON Web Tokens) 的使用者身份驗證與授權系統，有效保護使用者資料與 API 端點的安全
* 應用策略設計模式 (Strategy Pattern) 處理多變的行銷活動，將不同的折扣算法封裝為獨立的策略類，體現開放封閉原則
* 使用 Docker 容器化部署，建立 CI/CD 自動化流程，透過 GitHub Actions 部署至 Google Cloud Run

**技術棧：** Python, FastAPI, Next.js, Pydantic, Docker, GCP, Cloud Run, Firestore, JWT
